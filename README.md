# 🔥 Face Rating AI

Advanced AI-powered Face Rating Web App built using Flask, DeepFace, TensorFlow and Deep Learning.

## 🚀 Features

* 📷 Live Camera Face Detection
* 📂 Upload Image Support
* 🤖 AI Face Rating Prediction
* 🎨 Futuristic Glassmorphism UI
* 📱 Mobile Responsive Design
* ⚡ Fast Deep Learning Inference

## 🛠️ Technologies Used

* Flask
* TensorFlow
* Keras
* DeepFace
* OpenCV
* HTML
* CSS
* JavaScript
